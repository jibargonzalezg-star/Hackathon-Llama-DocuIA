# Hackathon 1: DocuIA - Asistente Inteligente con Llama 🦙

Asistente inteligente desarrollado para el cierre del **Módulo 1**, integrando modelos Llama, arquitectura RAG (Retrieval-Augmented Generation), FastAPI y una interfaz web interactiva.

## 🚀 Características Principales
* **Procesamiento de Documentos:** Carga y gestión de archivos PDF en tiempo real.
* **Recuperación y Generación (RAG):** Búsqueda de fragmentos relevantes basados en datos reales.
* **Interfaz Web Intuitiva:** Frontend construido con HTML5, CSS3 y JavaScript.
* **Backend Robusto:** API desarrollada con FastAPI.

## ⚙️ Instrucciones de Ejecución
1. Clona el repositorio.
2. Instala dependencias con `pip install -r requirements.txt`.
3. Ejecuta el servidor con: `uvicorn app:app --reload`.
4. Abre `http://127.0.0.1:8000` en tu navegador.
